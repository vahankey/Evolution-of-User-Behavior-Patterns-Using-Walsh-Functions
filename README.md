# Օգտատերերի թվային վարքագծի փոփոխությունների մոդելավորումը Ուոլշի ձևափոխությունների կիրառմամբ

ՆԵՐԱԾՈՒԹՅՈՒՆ
------------

### Թեմայի արդիականությունը

Ժամանակակից տեղեկատվական տեխնոլոգիաների դարաշրջանում օգտատերերի վարքագծի վերլուծությունը (User Behavior Analytics - UBA) դարձել է թվային էկոհամակարգերի անբաժանելի մասը: Յուրաքանչյուր վայրկյան գեներացվում են միլիոնավոր տվյալներ՝ սեղմումներ (clicks), էջերի դիտումներ, հավելվածներում տեղաշարժեր և գործարքներ: Այս տվյալները սովորաբար ներկայացված են ժամանակային հաջորդականությունների տեսքով, որոնք ունեն ընդհատ (discrete) և հաճախ բինար բնույթ:

Ավանդական վիճակագրական մեթոդները և Ֆուրիեի սպեկտրալ վերլուծությունը, որոնք հիմնված են սինուսոիդալ ֆունկցիաների վրա, միշտ չէ, որ արդյունավետ են նման «աստիճանաձև» և կտրուկ փոփոխվող ազդանշանների մշակման համար: Սինուսոիդալ ալիքները հարթ են, մինչդեռ մարդու թվային գործողությունները կտրուկ են (կատարվեց գործողություն կամ ոչ): Այստեղ է, որ առաջանում է Ուոլշի ֆունկցիաների կիրառման անհրաժեշտությունը:

Ուոլշի ֆունկցիաներն իրենց բնույթով ուղղանկյուն են և ընդունում են միայն երկու արժեք՝ $+1$ և $-1$: Սա նշանակում է, որ դրանք մաթեմատիկորեն ավելի համահունչ են թվային համակարգերի տրամաբանությանը: Ուոլշի ձևափոխության կիրառումը թույլ է տալիս նվազեցնել տվյալների չափողականությունը՝ պահպանելով վարքագծի կարևոր բնութագրիչները, իրական ժամանակում հայտնաբերել անոմալիաներ (օրինակ՝ բոտերի գրոհներ կամ համակարգի չնախատեսված սխալներ) և խմբավորել օգտատերերին՝ ըստ նրանց «թվային ձեռագրի» սպեկտրալ պատկերի:

### Աշխատանքի նպատակը և խնդիրները

Սույն դիպլոմային աշխատանքի նպատակն է մշակել և իրականացնել օգտատերերի թվային վարքագծի վերլուծության մեթոդաբանություն՝ հիմնված Ուոլշի ֆունկցիաների և սպեկտրալ դեկորելացիայի վրա:

Այդ նպատակին հասնելու համար աշխատանքում առաջադրվել և լուծվել են հետևյալ խնդիրները.

*   **Տեսական հետազոտություն**՝ ուսումնասիրել Ուոլշի ֆունկցիաների մաթեմատիկական ապարատը, Հադամարի մատրիցների կառուցման սկզբունքները և դրանց կապը սպեկտրալ վերլուծության հետ:
    
*   **Ալգորիթմական մշակում**՝ նկարագրել Արագ Ուոլշ-Հադամարի ձևափոխության (FWHT) կիրառման մեխանիզմը վարքագծային տվյալների վրա:
    
*   **Մոդելի կառուցում**՝ ստեղծել օգտատերերի կլաստերավորման և անոմալիաների հայտնաբերման մոդելներ՝ օգտագործելով ստացված Ուոլշի գործակիցները որպես հատկանիշներ (**features**):
    
*   **Ծրագրային իրականացում**՝ Python լեզվով մշակել համակարգ, որը թույլ կտա վիզուալիզացնել վարքագծի էվոլյուցիան և գնահատել առաջարկվող մեթոդի արդյունավետությունը:
    
*   **Փորձարարական ստուգում**՝ իրականացնել թեստավորում սինթետիկ և իրական տվյալների հավաքածուների վրա՝ համեմատելով արդյունքները ավանդական մեթոդների հետ:
